## Prácticas

Algunos recursos para practicar programación en Python:

* [Code Academy Python rack](http://www.codecademy.com/tracks/python): 
  Tutorial paso a paso a través de los conceptos básicos del lenguaje.

* [Project Euler](https://projecteuler.net/):
  un conjunto de tareas de programación cada vez más complejas para probar con Python.

## Bibliotecas interesantes para Ciencias:

* Astronomía: [AstroPy](http://astropy.org)

* Ciencias atmosféricas: [PyAOS](https://pyaos.github.io/)

* Biología: [Biopython](http://biopython.org/)

* Oceanografía y ciencias marinas: [OceanPython](http://oceanpython.org/)

* Recursos de psicología: [PyschoPy](http://www.psychopy.org/)

* Física cuántica: [QuTiP](http://qutip.org/)

* Física solar: [SunPy](http://sunpy.org/)
