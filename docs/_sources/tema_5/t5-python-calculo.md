# Cálculo Científico y Representación Gráfica con Python

En este tema, exploraremos el uso de la biblioteca NumPy para el cálculo científico y la representación gráfica en Python. [NumPy](https://numpy.org/) es una biblioteca fundamental para la computación científica en Python, que proporciona soporte para arreglos multidimensionales y una amplia gama de funciones matemáticas.

Sería el equivalente en Python de las operaciones matriciales y funciones matemáticas que se encuentran en software como MATLAB o R. Aprenderemos a utilizar NumPy para realizar operaciones matemáticas avanzadas, manipular datos y resolver problemas científicos.

Aquí teneis las diferencias con MATLAB:
[NumPy for MATLAB Users](https://numpy.org/doc/stable/user/numpy-for-matlab-users.html)

Además, veremos el uso de módulos adicionales como [Matplotlib](https://matplotlib.org/) para la visualización de datos y [SciPy](https://scipy.org/) para tareas avanzadas de cálculo científico.
